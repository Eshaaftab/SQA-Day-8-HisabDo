# SQA Day 8 – HisabDo Capstone Project

## 📌 Project Overview

This project was completed as part of the **SQA Internship Day 8 – Capstone Project**. The objective of this project was to understand and perform QA testing on the **HisabDo Web Application and Mobile Application**.

The testing was performed from a QA Engineer's perspective, covering functional, UI, usability, validation, positive, negative, boundary, compatibility, regression, and basic security testing.

## 🌐 Application Under Test

**Application:** HisabDo
**Type:** Accounting / Business Management Web & Mobile Application
